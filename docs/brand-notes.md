(Instagram blocks automated access, so the recording was the source). The layout system comes from the
ENZO reference in [`reference-notes.md`](reference-notes.md); everything below is One's own.

## Palette
Night `#0D100F` · Velvet Emerald `#123F33` · Deep Emerald `#0A2820` · Brass Gold `#C9A55C` · Soft Gold `#E2C88A` ·
Champagne `#F2E9DA` · Pool Glow `#3FD3C6` (accent only). All in `css/tokens.css`.

## Type
Bodoni Moda (headlines) · Josefin Sans (body/labels) · Pinyon Script (one flourish per layout). All Google Fonts.
